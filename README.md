# 📚 우리집 책장

집에 있는 책을 정리하는 간단한 웹 앱입니다. 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있어요.

## 기능

- **책 등록/수정/삭제** — 제목, 저자, 출판사, 분류, 메모
- **KDC(한국십진분류법) 분류** — 000 총류 ~ 900 역사 중에서 고르고, 문학은 형식(시, 소설, 수필, 작법 등)도 고를 수 있음 (예: 800 문학 · 소설)
- **소장 / 대여 구분** — 집에 있는 책과 도서관에서 빌려 본 책을 따로 기록하고 탭으로 나눠 보기 (대여는 도서관 이름도 기록)
- **읽기 상태 분류** — 안 읽음 / 읽는 중 / 읽음 탭으로 나눠 보기, 목록에서 바로 상태 변경
- **보유 여부 검색** — 제목·저자·출판사로 검색하면 집에 있는지 바로 알려줌
  - 집에는 없지만 빌려 본 적 있는 책이면 그것도 알려줌 (어느 도서관인지 포함)
  - 띄어쓰기와 대소문자는 무시 (`해리포터`로 검색해도 `해리 포터` 찾음)
  - 없는 책이면 "이 제목으로 추가" 버튼으로 바로 등록
- **중복 등록 경고** — 같은 목록(소장/대여)에 같은 책을 다시 추가하려 하면 알려줌
- **분류별 필터, 정렬** (최근 추가순 / 제목순 / 저자순 / 분류번호순), 상태별 통계
- **내보내기/가져오기** — JSON 파일로 백업하거나 다른 기기로 옮기기

## 사용법

1. `index.html`을 브라우저(크롬, 사파리, 엣지 등)로 엽니다.
2. `+ 책 추가`로 책을 등록합니다.
3. 책을 누르면 수정·삭제할 수 있습니다.

GitHub Pages를 켜면 휴대폰에서도 주소로 접속해 쓸 수 있습니다.

## 데이터 저장

데이터는 브라우저의 `localStorage`에 저장됩니다. 즉 **기기·브라우저마다 따로** 저장되고, 브라우저 데이터를 지우면 사라집니다.
가끔 `내보내기`로 백업 파일을 받아 두세요.

이전 버전에서 쓰던 "종류"는 처음 열 때 KDC로 자동으로 옮겨집니다 (소설 → 문학·소설, 시 → 문학·시 등).
KDC로 옮길 수 없는 종류(인문, 자기계발 등)는 메모에 `이전 종류: …`로 남겨 두니, 책을 눌러 분류를 골라 주세요.
