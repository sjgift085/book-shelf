# 📚 우리집 책장

집에 있는 책을 정리하는 간단한 웹 앱입니다. 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있어요.

## 기능

- **책 등록/수정/삭제** — 제목, 저자, 출판사, 종류(소설, 시, 에세이 등 — 직접 입력도 가능), 메모
- **읽기 상태 분류** — 안 읽음 / 읽는 중 / 읽음 탭으로 나눠 보기, 목록에서 바로 상태 변경
- **보유 여부 검색** — 제목·저자·출판사로 검색하면 "갖고 있는 책 N권" 또는 "갖고 있지 않은 책"으로 바로 알려줌
  - 띄어쓰기와 대소문자는 무시 (`해리포터`로 검색해도 `해리 포터` 찾음)
  - 없는 책이면 "이 제목으로 추가" 버튼으로 바로 등록
- **중복 등록 경고** — 같은 제목·저자의 책을 다시 추가하려 하면 알려줌
- **종류별 필터, 정렬** (최근 추가순 / 제목순 / 저자순), 상태별 통계
- **내보내기/가져오기** — JSON 파일로 백업하거나 다른 기기로 옮기기

## 사용법

1. `index.html`을 브라우저(크롬, 사파리, 엣지 등)로 엽니다.
2. `+ 책 추가`로 책을 등록합니다.
3. 책을 누르면 수정·삭제할 수 있습니다.

GitHub Pages를 켜면 휴대폰에서도 주소로 접속해 쓸 수 있습니다.

## 데이터 저장

데이터는 브라우저의 `localStorage`에 저장됩니다. 즉 **기기·브라우저마다 따로** 저장되고, 브라우저 데이터를 지우면 사라집니다.
가끔 `내보내기`로 백업 파일을 받아 두세요.
